3. **Error [ERR_MODULE_NOT_FOUND]: Cannot find package** — see [`node-err-module-not-found`](../errors/node-err-module-not-found.md)
4. **Error [ERR_REQUIRE_ESM]: require() of ES Module is not supported** — see [`node-err-require-esm`](../errors/node-err-require-esm.md)
5. **EADDRINUSE: address already in use :::3000** — see [`node-eaddrinuse`](../errors/node-eaddrinuse.md)
6. **FATAL ERROR: Reached heap limit Allocation failed - JavaScript heap out of memory** — see [`node-heap-oom`](../errors/node-heap-oom.md)
7. **node-gyp rebuild fails: 'Could not find any Python installation' / gyp ERR!** — see [`node-gyp-failed`](../errors/node-gyp-failed.md)
8. **npm ERR! Invalid package name "my-app": name can only contain URL-friendly characters** — see [`npm-einargs`](../errors/npm-einargs.md)
9. **npm ERR! code ETIMEDOUT / ECONNREFUSED registry.npmjs.org** — see [`npm-etimedout`](../errors/npm-etimedout.md)
10. **ESLint: Failed to load plugin 'react' declared in '.eslintrc': Cannot find module** — see [`eslint-plugin-missing`](../errors/eslint-plugin-missing.md)
