# The 10 git errors everyone hits twice

1. **! [rejected] main -> main (non-fast-forward) git push failed** — see [`git-non-fast-forward`](../errors/git-non-fast-forward.md)
2. **hint: You have divergent branches and need to specify how to reconcile them** — see [`git-divergent`](../errors/git-divergent.md)
3. **fatal: Unable to create '.git/index.lock': File exists** — see [`git-index-lock`](../errors/git-index-lock.md)
4. **You are in 'detached HEAD' state. You can look around, make experimental changes** — see [`git-detached-head`](../errors/git-detached-head.md)
5. **fatal: unable to auto-detect email address / wrong committer on push** — see [`git-author-identity`](../errors/git-author-identity.md)
6. **error: unable to create file ...: Filename too long (Windows)** — see [`git-filename-too-long`](../errors/git-filename-too-long.md)
7. **remote: Permission to X denied to Y. fatal: unable to access (403)** — see [`git-push-403`](../errors/git-push-403.md)
8. **error: Your local changes to the following files would be overwritten by checkout** — see [`git-checkout-conflict`](../errors/git-checkout-conflict.md)
9. **fatal: not a git repository (or any of the parent directories): .git** — see [`git-not-a-repo`](../errors/git-not-a-repo.md)
10. **error: ...: object is a file - replacing / fatal: bad object / packfile truncated** — see [`git-corrupt-obj`](../errors/git-corrupt-obj.md)
