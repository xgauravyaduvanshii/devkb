# error TS2554: Expected 2 arguments, but got 1

## Symptom

A call site complains about argument count after a signature change.

## Cause

The function gained a required parameter, or overload resolution picked a different signature than intended.

## Fix

1. Update the call site to match the new signature or make the new parameter optional.
2. If a type import shadowed a value, verify you imported the function not a type.

## Prevention

Export parameter objects instead of growing positional signatures; refactors then stay source-compatible.
