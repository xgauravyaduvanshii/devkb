# Cloudflare Error 521: Web server is down

## Symptom

Cloudflare returns 521 while your app looks healthy locally.

## Cause

Cloudflare could not reach the origin: origin server down, firewall blocking CF IPs, or the origin port (CF expects 80/443) is not open.

## Fix

1. Check origin uptime and logs.
2. Verify firewall allows Cloudflare IP ranges.
3. Confirm the origin listens on the port Cloudflare's SSL mode expects.

## Prevention

Monitor origin directly (uptime checks bypassing CF) so 5xx-from-edge never surprises you.
