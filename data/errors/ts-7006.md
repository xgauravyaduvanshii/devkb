# error TS7006: Parameter 'e' implicitly has an 'any' type

## Symptom

noImplicitAny rejects untyped callback params.

## Cause

A callback was added under noImplicitAny, or the array is any[] so context typing cannot infer the parameter.

## Fix

1. Annotate the parameter: (e: Event) => ....
2. If the source is any[], tighten its type so context inference works.

## Prevention

Type event handler factories once and reuse; enable noUncheckedIndexedAccess early to surface loose arrays.
