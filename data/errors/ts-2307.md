# error TS2307: Cannot find module 'x' or its corresponding type declarations

## Symptom

Import of an existing package/relative file fails type resolution.

## Cause

moduleResolution mismatch (e.g., bundler settings vs node16), missing @types for an untyped JS package, or path aliases not mirrored in tsconfig.

## Fix

1. Check the package ships types (types/exports fields).
2. Install @types/x or add a shim d.ts.
3. Align module/moduleResolution and paths with reality.

## Prevention

Keep one tsconfig per app with a documented module strategy (bundler vs NodeNext) and verify with tsc --noEmit in CI.
