# error TS1259: Module 'x' can only be default-imported using the 'esModuleInterop' flag

## Symptom

default import of a CommonJS package fails typecheck.

## Cause

esModuleInterop is off, so TS enforces strict CJS interop semantics where the package has only module.exports.

## Fix

1. Set esModuleInterop: true (and allowSyntheticDefaultImports).
2. Or import * as x / require style per package docs.

## Prevention

Standardize tsconfig with esModuleInterop for app codebases; libraries targeting Node may keep CJS semantics deliberately.
