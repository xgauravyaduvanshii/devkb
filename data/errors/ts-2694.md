# error TS2694: Namespace 'React' has no exported member 'FC' (or JSX types missing)

## Symptom

React/utility type references suddenly stop resolving.

## Cause

@types/react major bump moved or removed types, or JSX namespace changed in TS 5+, or the editor resolves a stale hoisted @types version.

## Fix

1. Check which @types/react version is installed (npm ls @types/react) and read its changelog for moved types.
2. Align TS and @types majors.
3. Dedupe hoisted types in monorepos.

## Prevention

Pin @types packages alongside the library they type, and update TS/@types in one deliberate PR per ecosystem.
